# Searchify — Music Finder Bot 🎵

Телеграм-бот для поиска музыки: отправьте ему название песни или имя
исполнителя — он найдёт трек и пришлёт аудио прямо в чат.

**Стек:** Python 3.11+, [aiogram 3](https://docs.aiogram.dev) (async),
aiohttp. Источники: Deezer, Audius и (опционально) Jamendo.

## Возможности

- 🔍 Поиск по названию песни или исполнителю одним сообщением
- 🆓 Полные MP3 (до 320 kbps) для легально свободной музыки — Audius,
  Jamendo
- 🎧 Официальные 30-секундные превью для чартовой/лейбловой музыки
- ▶️ Кнопки «открыть полную песню» в Яндекс Музыке, YouTube Music,
  Spotify, Deezer и Apple Music
- ⚡ Все источники опрашиваются параллельно; API-ключи не нужны
  (Jamendo — по желанию)

- Результаты с пометкой 🆓 (Audius, Jamendo) — легально свободная музыка,
  бот присылает **полный MP3-файл** прямо в чат.
- Остальные результаты (Deezer — там живёт вся чартовая музыка) приходят
  с официальным 30-секундным превью и кнопками, открывающими полную песню
  в Яндекс Музыке, YouTube Music, Spotify, Deezer и Apple Music.

## Установка

1. **Токен бота** — в Telegram откройте [@BotFather](https://t.me/BotFather),
   отправьте `/newbot`, задайте имя и username, оканчивающийся на `bot`.
   BotFather пришлёт токен вида `123456:ABC-DEF...`.
2. **Настройка** — скопируйте `.env.example` в `.env` и вставьте токен:
   ```
   BOT_TOKEN=123456:ABC-DEF...
   ```
   Необязательно: зарегистрируйте бесплатное приложение на
   [developer.jamendo.com](https://developer.jamendo.com) и впишите
   `JAMENDO_CLIENT_ID`, чтобы включить второй источник полных треков.
3. **Запуск** (из этой папки):
   ```powershell
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python bot.py
   ```

Откройте бота в Telegram, нажмите **Start** и введите название песни.

## Примечания

- Deezer и Audius работают без API-ключей; Jamendo — по бесплатному ключу.
- Полные файлы отправляются только для треков Audius/Jamendo, которые
  артисты выкладывают для свободного прослушивания. Лейбловая музыка
  отдаётся официальным 30-секундным превью плюс ссылками — бот
  сознательно не скачивает и не раздаёт лицензионные треки.
- Лимит Telegram на загрузку файла ботом — 50 МБ; более длинные треки
  пропускаются с уведомлением.
